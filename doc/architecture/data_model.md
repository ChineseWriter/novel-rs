# 核心数据结构

书籍对象包括以下几类数据:

1. 元数据: 包括书籍的唯一标识(HASH 值)、类型(仅小说和漫画)、标题、作者、简介.
2. 封面数据: 属于一种 Blob 数据.
3. 来源数据
4. 章节数据
5. 额外数据

请注意: 所有的 HSAH 值存储都不要使用 [u8; 64], 其一是长度固定, 不利于扩展; 其二是其会导致结构体本身较大, 不利于缓存命中; 其三是其拷贝的性能开销较大. 使用 Vec\<u8\>, Box<[u8]>, Arc<[u8]> 则可以避免这些问题.

## Blob 数据

在外部存储系统中的二进制数据, 只有两种类型: 图片数据(预先转换为 JPG)和文本数据. 该数据结构的内容包括:

1. Blob 数据的唯一标识(HASH 值)
2. Blob 数据的 MIME 类型
3. Blob 数据的大小(字节数)
4. Blob 数据在外部存储系统中的路径

请注意, 校验和的功能由唯一标识(HASH 值)提供, 因此不需要单独的校验和字段.

## 来源数据

来源数据本身为一个字符串.

## 章节数据

章节数据包括以下内容:

1. 唯一标识(HASH 值)
2. 序号
3. 标题
4. 更新时间
5. 正文内容(文本数据的 Blob 引用): 内部使用 HTML 格式, 若存在图片, 则使用 Blob 引用的 HASH 值作为 src 属性.
6. 来源
7. 额外数据
