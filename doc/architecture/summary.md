# 架构概述

## 总体架构概述

系统由四层组成：

1. 核心数据层：包含所有书籍基础数据及索引与检索功能，构成系统的底层支撑。
2. 功能层：由各独立功能模块组成，所有模块均基于核心数据层实现。
3. 整合层：负责将功能模块整合为整体，提供任务组合与调度能力，并向接口层暴露高级接口。
4. 接口层：对外提供用户界面和 API，与整合层交互以实现对外功能。

除这些层次结构外，系统所有层次与模块之间的数据流通均为 [Book 对象](./data_model.md)。

## 模块概述

### 核心数据层

- 书籍数据模块：存储并管理书籍的基础数据，支持小说与漫画两类数据结构。
- 索引与检索模块：提供高效的索引与检索能力，满足系统的查询需求。

### 功能层

功能层按职责可拆分为以下子层：

#### 数据输入与输出（所有输入均需进行数据清洗）

- 下载模块：从线上平台获取内容并写入核心数据层。
- 导入模块：从外部项目导入内容并写入核心数据层。
- 格式支持模块：连接系统内部的书籍数据（通常为类/对象）与多种电子书格式，提供导入/导出与格式转换功能。

#### 大模型赋能（需接入大模型服务）

- 书籍生成模块：提供书籍生成能力。
- 有声书模块：提供有声书生成能力。
- 分析模块：提供内容、结构与标签等分析能力。
- 编辑模块：提供内容编辑、结构编辑与标签编辑能力。

#### 额外数据产生（用户产生的补充数据）

- 笔记模块：管理笔记的创建、编辑与删除。
- 成就与生涯模块：管理成就与生涯相关数据。

#### 书架

面向用户的书籍管理（分类、排序、标签等），对索引与检索模块进行封装，提供更适合界面的管理能力。

### 整合层

任务调度模块：负责任务的组合与调度，与功能层各模块协作以实现复合业务流程。

### 接口层

- 用户界面模块：提供人机交互界面，并通过整合层实现业务功能。
- API 接口模块：对外暴露服务接口，与整合层协作以支持外部系统集成。
