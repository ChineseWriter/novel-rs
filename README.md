# 小说工具集

## 简介

这是一个用于处理小说的项目, 主要使用 Rust 编写, 集成了所有与小说阅读相关的功能. 现有的功能如下:

1. 下载: 该项目支持从多个在线平台下载小说.
2. 导入: 该项目支持从多个其它的 Github 相关项目导入小说.
3. 生成: 该项目支持使用大模型生成小说内容.
4. 特殊格式支持: 该项目支持将小说导入导出为各种常见的数据格式.
5. 有声书生成: 该项目支持将小说转换为有声书格式.
6. 编辑: 该项目支持多种方式对小说内容进行修改与微调.
7. 管理: 该项目支持对小说进行分类、标签化、搜索等管理功能.
8. 界面: 该项目使用网站的形式提供用户界面, 方便用户进行操作.
